# Data sources

Период выборки: `2010-01-04` - `2025-11-24`.

## Europe Brent Spot Price FOB

- Series ID: `DCOILBRENTEU`
- Source page: https://fred.stlouisfed.org/series/DCOILBRENTEU
- Direct CSV: https://fred.stlouisfed.org/graph/fredgraph.csv?id=DCOILBRENTEU&cosd=2010-01-04&coed=2025-11-24
- Units: U.S. dollars per barrel
- Frequency: daily

## Henry Hub Natural Gas Spot Price

- Series ID: `DHHNGSP`
- Source page: https://fred.stlouisfed.org/series/DHHNGSP
- Direct CSV: https://fred.stlouisfed.org/graph/fredgraph.csv?id=DHHNGSP&cosd=2010-01-04&coed=2025-11-24
- Units: U.S. dollars per million BTU
- Frequency: daily

## Nominal Broad U.S. Dollar Index

- Series ID: `DTWEXBGS`
- Source page: https://fred.stlouisfed.org/series/DTWEXBGS
- Direct CSV: https://fred.stlouisfed.org/graph/fredgraph.csv?id=DTWEXBGS&cosd=2010-01-04&coed=2025-11-24
- Units: index, January 2006 = 100
- Frequency: daily

The raw CSV snapshots are retained to make the analysis reproducible when FRED is unavailable or a network connection is restricted.
