# Energy market time-series analysis

Воспроизводимый проект по эконометрике временных рядов на ежедневных данных энергетического и валютного рынков за период с 4 января 2010 года по 24 ноября 2025 года.

Исследование объединяет два взаимосвязанных этапа:

1. одномерное моделирование логарифмических доходностей Brent с помощью ARIMA;
2. многомерный анализ логарифмических доходностей Brent, Henry Hub и широкого индекса доллара США с помощью VAR.

## Основные результаты

Логарифм цены Brent нестационарен, тогда как логарифмические доходности стационарны. Для условного среднего доходностей экономная ARIMA(0,0,0) с нулевым средним даёт практически нулевой точечный прогноз; при этом диагностика указывает на кластеры волатильности и тяжёлые хвосты, которые линейная ARIMA-модель не описывает.

В VAR(2) собственные лаги оказываются содержательнее перекрёстных. Причинность по Грейнджеру между доходностями Brent, газа и индекса доллара не подтверждается на стандартном уровне значимости. Импульсные отклики быстро затухают, а большая часть дисперсии ошибки прогноза каждой переменной объясняется её собственными шоками.

## Данные

Проект использует три ряда из базы FRED:

| Код | Ряд | Единицы |
|---|---|---|
| `DCOILBRENTEU` | Europe Brent Spot Price FOB | доллары США за баррель |
| `DHHNGSP` | Henry Hub Natural Gas Spot Price | доллары США за MMBtu |
| `DTWEXBGS` | Nominal Broad U.S. Dollar Index | индекс, январь 2006 = 100 |

Скрипт сначала пытается скачать данные напрямую по официальным CSV-ссылкам FRED. Если интернет недоступен, он использует снимки из `data/raw/`. Период зафиксирован, поэтому результаты остаются сопоставимыми с аналитической запиской.

Чтобы принудительно использовать только локальные файлы:

```bash
REFRESH_DATA=false Rscript run_all.R
```

В RStudio можно выполнить:

```r
Sys.setenv(REFRESH_DATA = "false")
source("run_all.R")
```

## Запуск

Требуется R версии 4.3 или новее.

```bash
Rscript install_packages.R
Rscript run_all.R
```

Либо из RStudio:

```r
source("install_packages.R")
source("run_all.R")
```

Команды нужно выполнять из корневой папки проекта. Графики сохраняются в `results/figures/`, таблицы и текстовые результаты тестов - в `results/tables/`.

## Воспроизводимость

- установка пакетов вынесена в отдельный файл;
- загрузка данных не зависит от ручного выбора CSV;
- локальные копии позволяют запустить анализ без доступа к FRED;
- случайная генерация и bootstrap-оценивание IRF используют фиксированное начальное значение генератора;
- все рисунки и таблицы записываются в стандартные папки проекта;
- GitHub Actions запускает анализ на локальных снимках данных при каждом обновлении основной ветки.

## Ограничения

ARIMA и VAR моделируют условное среднее. Выраженная гетероскедастичность и ненормальность остатков показывают, что для отдельного исследования волатильности уместно расширение с GARCH-моделями. Выводы об импульсных откликах зависят от рекурсивной идентификации и порядка переменных в VAR, поэтому не интерпретируются как структурные причинные эффекты.
