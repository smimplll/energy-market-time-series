# Energy market time-series analysis

Было исследовано, насколько прошлые изменения цен на нефть Brent, природный газ Henry Hub и динамика широкого индекса доллара США объясняют и прогнозируют доходность Brent.

В работе используются ежедневные данные FRED с 4 января 2010 года по 24 ноября 2025 года. Анализ состоит из двух частей: сначала временной ряд Brent рассматривается отдельно с помощью ARIMA, затем совместная динамика нефти, газа и индекса доллара оценивается с помощью VAR.

## Основной результат

Прошлые значения доходности Brent почти не улучшают её краткосрочный прогноз: выбранная ARIMA-модель формирует точечный прогноз, близкий к нулю. Добавление доходностей Henry Hub и индекса доллара в VAR также не создаёт заметного преимущества — перекрёстные эффекты малы, а импульсные отклики быстро затухают.

При этом ряд содержит выраженные периоды высокой и низкой волатильности и экстремальные изменения. Поэтому основная структура данных проявляется скорее в изменяющейся дисперсии, чем в устойчиво предсказуемой средней доходности.

## Данные и воспроизводимость

При обычном запуске скрипт пытается скачать три ряда напрямую из FRED. Если соединение недоступно, используются локальные копии из `data/raw/`, поэтому ручной выбор и импорт файлов не требуются.

Чтобы принудительно использовать только локальные данные:

```r
Sys.setenv(REFRESH_DATA = "false")
source("run_all.R")
```

## Запуск

Требуется R версии 4.3 или новее. Команды выполняются из корневой папки проекта:

```r
source("install_packages.R")
source("run_all.R")
```

Или из терминала:

```bash
Rscript install_packages.R
Rscript run_all.R
```

Графики сохраняются в `results/figures/`, таблицы и результаты статистических тестов — в `results/tables/`, подготовленные ряды — в `data/processed/`.

## Ограничения интерпретации

ARIMA и VAR описывают условное среднее временных рядов и не моделируют выявленную изменчивость волатильности. Отсутствие статистически значимой причинности по Грейнджеру не доказывает отсутствие экономической связи между рынками. Ортогонализованные импульсные отклики также зависят от порядка переменных в VAR и не интерпретируются как структурные причинные эффекты.
